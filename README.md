# College Beamer

College Beamer is a collection of institution-branded LaTeX Beamer themes. It supports English and Chinese presentations and provides coordinated logos, colors, title backgrounds, section dividers, code listings, and closing slides.

The project is based on the [SINTEF Presentation](https://www.overleaf.com/latex/templates/sintef-presentation/jhbhdffczpnx) template created by [Federico Zenith](mailto:federico.zenith@sintef.no). It began as an adaptation for The Hong Kong Polytechnic University and has grown through contributions from students and researchers at other institutions.

## Usage

### Quick start

A TeX distribution with Beamer and `latexmk` is required. Clone the repository, edit `pre.tex`, and compile it with XeLaTeX:

```bash
git clone https://github.com/liu-qilong/college-beamer.git
cd college-beamer
latexmk -xelatex -interaction=nonstopmode pre.tex
```

XeLaTeX works with both supported languages and is required for Chinese. English presentations can alternatively be compiled with pdfLaTeX:

```bash
latexmk -pdf -interaction=nonstopmode pre.tex
```

### Select an institution and language

Pass one institution option from the gallery and one language option to the package:

```latex
\usepackage[polyu,en]{collegebeamer}
```

Use `en` for English or `zh` for Chinese. For example, the following selects the Harbin Engineering University theme in Chinese:

```latex
\usepackage[heu,zh]{collegebeamer}
```

Institution option codes are lowercase and must match the **Option** column exactly.

## Create an institution theme

New themes reuse the common layouts in `collegebeamer.sty` and supply institution-specific colors and artwork.

### Step 1: Fork and clone the repository

Fork the project on GitHub, then clone your fork:

```bash
git clone https://github.com/<your-username>/college-beamer.git
cd college-beamer
```

You can also start from one of the linked Overleaf templates by selecting **Open as Template**, although this repository contains the most current version.

### Step 2: Add the artwork

Create a directory under `src/` for the institution and add three assets:

```text
src/MyCollege/
├── color-logo.png
├── trans-logo.png
└── background.png
```

- `color-logo` is displayed on white slides; a 906 x 1134 (width x height) size image is recommended.
- `trans-logo` is displayed on colored slides and should normally have a transparent background; a 906 x 1134 (width x height) size image is recommended.
- `background` fills the title slide; a 16:9 image is recommended.

PNG and PDF assets are both supported. Their extensions and capitalization must match the paths declared in `collegebeamer.sty`. If a transparent logo is unsuitable for your branding, see [issue #8](https://github.com/liu-qilong/college-beamer/issues/8) for guidance on using a white-backed logo.

### Step 3: Declare the option

In the `colleges & institutes` section of `collegebeamer.sty`, add a unique lowercase option code and point it to the new assets:

```latex
\DeclareOption{mycollege}{
  \renewcommand{\maincolorRGB}{12, 34, 56}
  \renewcommand{\colorlogoPath}{src/MyCollege/color-logo.png}
  \renewcommand{\translogoPath}{src/MyCollege/trans-logo.png}
  \renewcommand{\backgroundPath}{src/MyCollege/background.png}
}
```

The main color is used for titles, highlights, and section-divider backgrounds.

### Step 4: Preview and document the theme

Before opening a pull request:

1. Add the option code to the list at the top of `pre.tex`.
2. Select the option in `pre.tex` and update its title, author, and date.
3. Compile the presentation and check both logos, the title background, section dividers, and text contrast.
4. Export a representative screenshot to `gallery/`.
5. Add one row to the gallery table, including the option code, preview, and contributor credit.

Your theme is then ready for a pull request.

## Tips

### Page numbers

College Beamer displays the current frame and total frame count on standard content slides by default. Title, section-overview, and Q&A slides intentionally omit the footer.

If another customization replaces the footline, add the following after loading `collegebeamer` to restore page numbers:

```latex
\setbeamertemplate{footline}{%
  \begin{beamercolorbox}[
    wd=\paperwidth,
    ht=3ex,
    dp=1.5ex,
    rightskip=1cm
  ]{footline}
    \hfill\insertframenumber/\inserttotalframenumber
  \end{beamercolorbox}%
}
```

### Block appearance

The default block design reflects the maintainer's personal aesthetic for the PolyU template: rounded corners, compact type, soft-gray surfaces, air-force-blue headings, and dark-gray body text. This understated appearance is applied consistently across institution themes, but it is a design preference rather than a branding requirement.

You can override it in the preamble after loading `collegebeamer`. For example, the following uses the selected institution's `maincolor` and adds a subtle shadow:

```latex
\setbeamertemplate{blocks}[rounded][shadow=true]
\setbeamerfont{block title}{series=\bfseries, size=\small}
\setbeamerfont{block body}{size=\scriptsize}
\setbeamercolor{block title}{fg=white, bg=maincolor}
\setbeamercolor{block body}{fg=darkgray, bg=maincolor!8}
```

Alert and example blocks have separate Beamer color keys and can be customized independently:

```latex
\setbeamercolor{block title alerted}{fg=white, bg=red!75!black}
\setbeamercolor{block body alerted}{fg=black, bg=red!8}

\setbeamercolor{block title example}{fg=white, bg=green!45!black}
\setbeamercolor{block body example}{fg=black, bg=green!8}
```

Use `\setbeamertemplate{blocks}[default]` instead if you prefer square corners.

### Presenter notes with XeLaTeX

When compiling with XeLaTeX and enabling Beamer's presenter-note mode,

```latex
\setbeameroption{show notes on second screen}
```

the text color on some slides may become incorrect (for example, normal text may unexpectedly appear white).

This is an upstream Beamer issue rather than a bug in `college-beamer`; see [beamer#337](https://github.com/josephwright/beamer/issues/337). The issue and workaround were reported and investigated in [college-beamer#45](https://github.com/liu-qilong/college-beamer/issues/45).

A workaround is to reset the foreground color at the beginning of each frame's notes. Place this patch in the preamble after loading `collegebeamer`:

```latex
\makeatletter
\pretocmd{\beamer@framenotesbegin}
  {\usebeamercolor[fg]{normal text}}
  {}{}
\makeatother
```

`collegebeamer` already loads `etoolbox`, so no additional package is required for `\pretocmd`.

Bug reports and suggestions are welcome through [GitHub Issues](https://github.com/liu-qilong/college-beamer/issues). Please include the compiler, package options, and relevant log output when reporting a build problem.
